# ChipGroup

APG 대응: 그룹 이름 부여 + (선택 그룹이면) 단일/다중 선택 의미 전달.

ChipGroup은 **레이아웃 컨테이너**다 — 칩 자체 의미는 Chip이 갖고(→ `chip.md`), 그룹은 (1) 이름, (2) 선택 의미, (3) 배치(줄바꿈/스크롤)를 담당한다.

---

## 그룹에 이름

라벨이 있으면 그룹과 연결한다.

```tsx
<div role="group" aria-labelledby="cg-label">
  <span id="cg-label">관심 카테고리</span>
  …칩들…
</div>
```

`<fieldset>`/`<legend>`도 가능. 라벨 없이 칩만 나열하면 스크린리더 사용자가 "무엇을 고르는지" 모른다.

## 필수 표시

라벨의 마젠타 `*`는 **시각 표시일 뿐**이다. 필수임을 `aria-required`(또는 안내 문구)로도 전달한다. `*`만으로는 접근성 정보가 아니다.

## 선택 의미

- **다중 선택**이면 각 칩의 `aria-pressed`로 충분하고 그룹은 `role="group"`.
- **하나만** 선택하는 구조면 라디오 의미에 가깝다 — Chip 대신 Radio를 검토하거나, 그룹의 단일 선택 규칙을 명확히 안내한다.

## 배치는 의미가 아니다

`wrap`(줄바꿈) vs 가로 스크롤은 시각 배치일 뿐 접근성 트리에는 영향이 없다. 단, 가로 스크롤이면 키보드로 스크롤·포커스 이동이 되는지 확인한다.

---

## 체크리스트

| # | 항목 | 검사법 |
|---|---|---|
| CG1 | 그룹에 이름(`role="group"`+`aria-labelledby` 또는 `fieldset`/`legend`) | 라벨 연결 |
| CG2 | 필수를 `*` 시각 외에 `aria-required`/문구로 전달 | 해당 시 |
| CG3 | 각 칩의 선택이 `aria-pressed`로 노출됨(→ `chip.md`) | 칩 확인 |
| CG4 | "하나만" 선택이면 Radio 검토 | 의미 확인 |
| CG5 | 가로 스크롤 시 키보드 접근 가능 | 해당 시 |
